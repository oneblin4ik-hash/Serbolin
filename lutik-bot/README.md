# 🦝 Енот Лютик — Telegram-бот (v2)

Личный ИИ-ассистент Эдуарда Серболина. Принимает задачи, отчёты и голосовые в Telegram (@MrSerbolinbot), ведёт систему жизни в Notion. Один Cloudflare Worker, без своей БД (состояние — в KV). Мозг: Google Gemini (`gemini-2.5-flash` + фолбэк `gemini-2.5-flash-lite`).

```
Telegram + cron → Worker → Gemini (OpenAI-совместимый endpoint: классификация)
                         → Gemini (нативный endpoint: распознавание голоса)
                         → Notion API (базы «Системы жизни»)
                         → Telegram Bot API (ответы, посты в канал)
```

## Что умеет

| Сообщение / команда | Действие |
|---|---|
| 🎙 **голосовое** | распознаётся через Gemini и идёт в общий пайплайн как текст |
| «сегодня: снять рилс, тренировка в 12…» | задачи в Notion (Сегодня ✓, дата, день недели, сфера) |
| «добавь / надо / не забыть…» | одна задача |
| «Аня из инсты хочет консультацию в субботу» | запись в Лидах |
| «сделал то-то…» или `/done <отчёт>` | задачи → Готово, привычки → журнал, нумерованный список несделанного |
| «перенеси 1 и 3, второе сними» | интерактивный перенос/снятие по номерам |
| «заявок 3, роликов 5, IG 8600, TG 410» | upsert строки в базе «Метрики недели» |
| «идея для рилса: …» | страница в Базе знаний (Тип = Идея, Область = контент) |
| «запости в канал: …» | предпросмотр → кнопка подтверждения → пост в канал |
| «запости в канал завтра в 10: …» | отложенный пост (публикуется ежечасным cron) |
| `/today` | план дня по приоритетам + привычки |
| `/week` | обзор недели по статусам |
| `/habits` | стрики привычек (🔥 N подряд) |
| `/lead` | воронка CRM + последние заявки |
| `/done` | вечерний отчёт |

Сообщения с чужих chat_id игнорируются (заглушка «Я личный ассистент Эдуарда 🦝»).

## Cron-расписание (UTC; владелец в UTC+5)

| Cron (UTC) | Время Екб | Что делает |
|---|---|---|
| `0 2 * * *` | 07:00 | утренний автобриф (план дня + привычки дня + «⚠️ Лиды ждут») |
| `30 16 * * *` | 21:30 | напоминание об отчёте, если за день его не было |
| `0 14 * * 0` | 19:00 вс | недельный обзор + опрос метрик |
| `0 * * * *` | ежечасно | публикация отложенных постов в канал |

## Деплой

```bash
cd lutik-bot
npm install

# 1. Секреты (4 шт.)
npx wrangler secret put TELEGRAM_BOT_TOKEN       # от BotFather
npx wrangler secret put TELEGRAM_WEBHOOK_SECRET  # случайная строка: openssl rand -hex 32
npx wrangler secret put AI_API_KEY               # Google AI Studio (Gemini API key)
npx wrangler secret put NOTION_TOKEN             # notion.so/my-integrations

# 2. KV namespace (обязателен в v2: дедуп апдейтов, контекст, флаги, отложенные посты)
npx wrangler kv namespace create LUTIK_CONTEXT
#    → вставить выданный id в wrangler.toml (поле id вместо REPLACE_WITH_KV_NAMESPACE_ID)

# 3. База «Метрики недели» в Notion
#    Создать базу со свойствами: Неделя (title), Заявки, Ролики, Подписчики IG,
#    Подписчики TG, Новые клиенты (number), Комментарий (rich_text).
#    Расшарить её интеграции, скопировать ID из URL → вписать в src/config.ts → METRICS_DB.

npx wrangler deploy
```

Интеграции Notion нужно выдать доступ к странице-хабу «Система жизни — Эдуард» (все базы внутри неё) и к базе «Метрики недели».

Регистрация webhook (подставить токен, секрет и URL воркера из вывода deploy):

```bash
curl "https://api.telegram.org/bot<TOKEN>/setWebhook" \
  -d "url=https://lutik-bot.<account>.workers.dev/webhook" \
  -d "secret_token=<TELEGRAM_WEBHOOK_SECRET>"
```

Для постинга в канал бот должен быть админом канала (`CHANNEL_ID` уже в `config.ts`).

## Приёмочные тесты v2

1. Голосовое «сегодня снять рилс и тренировка» → 2 задачи в Notion
2. `curl "http://localhost:8787/__scheduled?cron=0+2+*+*+*"` (в `wrangler dev`) → приходит утренний бриф
3. Повторный POST того же `update_id` → задача создаётся один раз (дедуп через KV)
4. «отчёт: всё сделал» → вечером 21:30 напоминание не приходит (флаг `report_done`)
5. «заявок 3, роликов 5, IG 8600, TG 410» → строка в «Метриках недели»
6. «перенеси 1, второе сними» после отчёта → статусы/даты меняются верно
7. «запости в канал: тест» → предпросмотр → кнопка → пост в канале

## Логи

```bash
npx wrangler tail
```

Любая ошибка Notion/Gemini не роняет воркер: пользователю уходит «🦝 Споткнулся: …», детали — в логах. Ошибки cron логируются; пользователю шлются только для пользовательских задач (бриф/напоминание/обзор).

## Структура

```
src/
  index.ts     — fetch (webhook) + scheduled (роутинг по cron)
  handlers.ts  — маршрутизация, интенты, голос, callback-кнопки, /today /week /habits /lead, cron-задачи, KV
  brain.ts     — Gemini: классификация (OpenAI-совместимый) + распознавание аудио (нативный) + сопоставление отчёта
  notion.ts    — операции с базами Notion (задачи, лиды, привычки, метрики, знания)
  telegram.ts  — sendMessage, inline-кнопки, callback, getFile/download
  config.ts    — ID баз, сферы, METRICS_DB, константы, Env
  dates.ts     — даты в UTC+5, ISO-неделя, плановые дни привычек
```
