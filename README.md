# SSS — Супер Система Серболина

Личное веб-приложение с геймификацией: задачи и цели прокачивают «персонажа».
Сделано для себя, работает полностью локально в браузере — данные хранятся в
`localStorage` твоего устройства.

## Быстрый старт

Нужен **Node.js 18+** ([скачать](https://nodejs.org/)). В папке проекта:

```bash
npm install
npm run dev
```

Открой в браузере адрес, который покажет Vite (обычно
`http://localhost:5173`). Приложение готово к использованию.

Чтобы собрать «готовую» версию для размещения на любом статическом хостинге:

```bash
npm run build
```

Готовые файлы окажутся в папке `dist/`.

## Что есть в v1

- **Задачи и Цели** — чек-листы с XP-наградой, категории, ежедневный сброс
  повторяющихся задач, цели с пошаговым прогрессом.
- **Персонаж** — уровень, XP-бар, 4 характеристики (Сила воли, Дисциплина,
  Фокус, Креатив), редактирование имени и аватара.
- **Общий каркас** — боковое меню, топбар с датой, быстрое добавление,
  toast-уведомления, всплывающие «+XP», адаптив под телефон.

Разделы «Главная», «Личный кабинет», «CRM / Лиды», «Контент-план» показывают
заглушку «в разработке» — они появятся в следующих итерациях.

## Технологии

- React 18 + Vite 5
- Tailwind CSS 3
- Zustand (состояние, `persist` в `localStorage`)
- React Router 6
- Lucide React (иконки)

## Структура

```
src/
  layout/      # Sidebar, Topbar, Layout
  pages/       # TasksPage, CharacterPage, ComingSoon
  features/    # tasks/ (формы, карточки)
  components/  # Modal, Toasts, XpPopup, Avatar
  store/       # useCharacterStore, useTasksStore, useUiStore
  lib/         # xp.js, dates.js, constants.js
```

## Claude Code на всех устройствах

Этот репозиторий также настроен для работы с **Claude Code** на вебе,
десктопе (CLI) и мобильном.

- `.claude/settings.json` — общие настройки и SessionStart-хук.
- `.claude/hooks/session-start.sh` — поднимает окружение (ставит
  зависимости `npm / pip / poetry / cargo / go / bundler`, если они есть).

### CLI

```bash
npm install -g @anthropic-ai/claude-code
claude
```

### Веб

Зайди на **https://claude.ai/code** и подключи этот репозиторий. Хук
запустится автоматически.

### Мобильный

Установи приложение Claude (iOS / Android), войди тем же аккаунтом, подключи
репозиторий — сессия и настройки те же, что и на ПК.
